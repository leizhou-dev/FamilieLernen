# Familie lernt · 家庭学习

家庭自用的学习 PWA，统一 Artikel lernen、Latein lernen 和 Mac 学习工具的入口，并支持之后加入新的学习模块。

## 功能

- **家庭档案**：打开时进入上次使用的档案，点右上角头像切换。每个档案有自己的名字、头像、颜色、界面语言和解析语言。
- **课程**：每个档案可以添加、继续或隐藏课程。同一门课可以加入多个档案，各自保存记录。隐藏后重新添加，进度保留。
- **主导航**：今天 · 课程 · 复习。
- **三语界面**：简体中文 / English / Deutsch，切换立即生效。学习材料保持课程原语言；解析默认跟随界面，也可单独选择，没有所选语言时会标明实际语言。
- **Artikel lernen 和 Latein lernen**：两个 App 完整内置（全部练习、游戏、词卡和语法都在），在课程页打开。每个家庭档案有自己的进度；课程界面保持德语。
- **德语 A1–B2**：级别 → 单元 → 活动 → 题目。活动类型包括词汇、语法、听力、阅读、写作、口语；练习支持词卡、选择、填空、开放写作和口语录音。没有内容的单元和活动显示「待添加」。
- **续学与复习**：按档案和课程保存学习位置、完成情况、错题和收藏；中途关闭后从原题继续。
- **家庭密码**：和 Latein lernen 一样，课程内容加密发布，每台设备第一次打开时输入一次家庭密码，之后自动解锁；可在设置里锁定。
- **离线**：可添加到 iPad / iPhone 主屏幕，离线也能使用。第一版的记录只保存在当前设备，可在设置里导出备份。
